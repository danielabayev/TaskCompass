Task types and what each accepts as a done test:
- build: a working thing you can run or show. Done test example: "the page opens at localhost and shows the list?"
- fix: a problem that no longer happens. Done test example: "the steps that caused the bug no longer cause it?"
- learn: an ability you can demonstrate, with evidence. Done test example: "I solved 3 exercises on JOIN without looking at notes?" ("I understand X" is not acceptable.)
- write: a finished text in a known place. Done test example: "the email was sent to the manager?"
- decide: a written decision with its reasoning. Done test example: "a note exists with the chosen option and two reasons?" ("I thought about it" is not acceptable.)
- errands: a list of concrete actions that were carried out. Done test example: "the package was collected from the post office?"
